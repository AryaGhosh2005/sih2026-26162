# THERMOSCOPE

### AI-Powered Satellite Thermal Intelligence Platform

> SIH 2026 — Problem Statement 26162  
> National Technical Research Organisation (NTRO)

## Overview

THERMOSCOPE is a geospatial intelligence platform designed to
detect, classify and prioritize industrial fires and persistent
thermal sources using satellite thermal-anomaly data,
geospatial infrastructure and temporal analysis.

## Core Pipeline

NASA FIRMS
↓
Thermal Anomaly Detection
↓
Geospatial Context
↓
Industrial Proximity Analysis
↓
Persistence Analysis
↓
AI Classification
↓
Risk Assessment
↓
Interactive GIS Dashboard

## Key Features

- Satellite thermal hotspot visualization
- Industrial facility identification
- Thermal-source classification
- Persistent thermal-source detection
- Contextual risk scoring
- Interactive GIS intelligence dashboard
- Incident analysis and reporting
